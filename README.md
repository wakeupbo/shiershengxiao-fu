# 十二生肖

十二生肖主题的文字合成塔防小游戏。项目把生肖年画题材、令牌式字块合成、沿路塔防和上下分屏对战放在同一个 Canvas 游戏里，并补齐了网页端公网玩家对战、账号体系和战绩留存。

玩法与架构沿用开源项目 `maojunzc/wukong-tangseng`，仅替换主题层（名称 / 兵种 / 武将 / 地图 / 美术 / 文案），核心合成、寻路、对战与在线逻辑保持不变。详见 `new_readme.md`《十二生肖设计文档》。

## 核心玩法

- 战场为 8 x 10 格地图，上半场属于对手，下半场属于玩家，中间山脊分隔。
- 敌人会沿各自的 S 形道路进攻守将，漏过一个敌人扣 1 颗红心，守将红心归零即失败。
- 玩家消耗「仙桃」进行「征兵」抽字牌，拖到道路旁的白色可建造格布阵。
- 基础兵种包括「爪」「角」「牙」「翼」，同字同级二合一升级，最高 5 级。
- 征兵也可能抽到金色生肖碎片，拼齐姓名后觉醒武将。每局从 6 个武将中随机出现 4 个：子鼠、丑牛、寅虎、卯兔、辰龙、巳蛇。
- 地图会在鼠洞、牛栏、虎穴、兔窝、龙宫之间随机切换。
- 守将为红色菱形「福」字，3 颗红心。
- 单人 AI 对战撑过目标波次，或先耗光对手红心，即可获胜；公网 PvP 为无尽模式，只有一方死亡、投降或断线才会结束。

## 兑换码

兵器库默认需要兑换码解锁。开始页点击「兑换兵器」输入任意有效兑换码即可永久解锁；解锁后也可以在兵器库右上角继续输入其他兑换码领取奖励。每个兑换码会发放对应品质的全部未拥有武器，并且在本地存档中只能使用一次。

| 兑换码 | 奖励品质 |
| --- | --- |
| `maojunzc666` | 全套良品武器 |
| `maojunzc888` | 全套珍品武器 |
| `maojunzc999` | 全套神器武器 |

## 公网对战流程

1. 打开公网地址，点击「公网大厅」。
2. 首次使用选择「注册新账号」，已有账号选择「登录账号」。
3. 房主点击「创建房间」。
4. 复制邀请链接或房间码发给对手。
5. 对手打开邀请链接，或在大厅输入房间码加入。
6. 房间内确认双方玩家、在线状态和准备状态。
7. 双方都点击「我已准备」后自动开局。
8. 公网 PvP 没有第 10 波胜利结算；一方死亡、投降或断线后，服务端记录双方胜负、波次和最近对局。

## 本地运行

安装依赖并启动公网对战服务：

```bash
npm install
npm start
```

默认监听 `0.0.0.0:8787`，浏览器打开：

```text
http://localhost:8787/
```

只验证单机网页版本时，也可以直接用静态服务器打开：

```bash
python3 -m http.server 8765
```

然后访问：

```text
http://localhost:8765/index.html
```

挂机调试模式：

```text
http://localhost:8765/index.html?bot=1
```

## 部署说明

公网对战服务由 `server/online-server.js` 提供，依赖 Node.js 20+ 和 `ws`。

常用环境变量：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `8787` | HTTP 与 WebSocket 服务端口 |
| `HOST` | `0.0.0.0` | 监听地址 |
| `ONLINE_DATA_FILE` | `data/online-store.json` | 账号、会话、战绩和对局记录的持久化 JSON 文件 |

示例：

```bash
ONLINE_DATA_FILE=/var/lib/wukong-tangseng/online-store.json npm start
```

如果前端部署在 GitHub Pages、Vercel 或对象存储等静态站，而 WebSocket 服务部署在另一台服务器，可以通过查询参数指定服务地址：

```text
https://你的静态站/index.html?ws=wss://你的域名/ws
```

未配置 TLS 的测试环境可用：

```text
http://你的静态站/index.html?ws=ws://服务器IP:8787/ws
```

## 小游戏平台发布

### 微信小游戏

1. 在微信公众平台注册小游戏账号，获取 AppID。
2. 使用微信开发者工具导入本项目根目录。
3. 将 `project.config.json` 中的 `appid` 从 `touristappid` 改为实际 AppID。
4. 在开发者工具中预览、真机调试、上传并提交审核。

### 抖音小游戏

1. 在抖音开放平台注册小游戏，获取 `tt` 开头的 AppID。
2. 使用抖音开发者工具导入本项目根目录。
3. 将 `project.douyin.config.json` 重命名为 `project.config.json`，并填入实际 AppID。
4. 预览确认后上传并提交审核。

`js/adapter.js` 与 `js/audio.js` 已处理 `wx.*`、`tt.*` 和浏览器环境差异，核心游戏逻辑保持同源。

## 项目结构

```text
game.js                    小游戏入口
game.json                  小游戏配置
project.config.json        微信开发者工具项目配置
project.douyin.config.json 抖音开发者工具项目配置
index.html                 浏览器入口
.github/workflows/         GitHub Actions 工作流（发布静态网页版到 GitHub Pages）
js/                        Canvas 游戏核心、UI、AI、在线对战客户端
audio/                     程序生成的 WAV 音效
server/                    公网对战 WebSocket 房间服务与测试
sim/                       无头模拟器，用于 AI 与数值平衡验证
tools/                     开发工具，例如音效生成脚本
docs/screenshots/          README 使用的游戏内截图
```

## 后续优化方向

- 注册和登录改为正式弹窗表单，增加输入校验、错误提示和更完整的账号管理体验。
- 增加快速匹配池，让没有邀请链接的玩家也能自动匹配对手。
- 完善断线重连，在网络波动后恢复房间、准备状态和对局进度。
- 增强结算页，展示伤害、建造、合成、武将觉醒和关键波次等统计。
- 增加排行榜、赛季、段位积分和历史战绩详情。
- 引入服务端权威校验与反作弊策略，避免客户端伪造关键对局结果。
- 继续用 `sim/` 做数值回归，确保 AI 后期压力、武将强度和经济曲线稳定。
